# Подпись WorkshopSentinel

**Подпись отложена. Текущая поставка неподписанная; профиль Steam менять не нужно.** Загрузка JAR подтверждается обычным запросом ZombieBuddy. Ключ сохранён отдельно на будущее. Инструкция ниже применяется только при явном возобновлении подписи.

Автор: [i218](https://steamcommunity.com/id/i218/), SteamID64 `76561199013754121`.

## Один раз перед установкой подписанной версии

В Steam откройте «Редактировать профиль», добавьте эту строку в описание профиля и сохраните. Описание должно быть доступно публично:

```text
JavaModZBS:a2f8023e10e1205ad5d10c9e12bae6ef7765b7825f600c65d3796573ea17c306
```

Это публичный ключ: его можно показывать и распространять. Без публикации ключа ZombieBuddy не сможет подтвердить подпись через профиль. Альтернатива для приватного профиля — регистрация публичного ключа в списке авторов ZombieBuddy через PR в `authors/` его официального репозитория.

После публикации установите подписанную сборку и при запросе ZombieBuddy один раз выберите доверие автору. На каждом компьютере/сервере доверие задаётся отдельно. Следующие подписанные сборки того же автора могут загружаться автоматически согласно политике ZombieBuddy.

## Что находится в установщике

`42/media/java/WorkshopSentinel.jar` и `WorkshopSentinel.jar.zbs` рядом с ним. Подпись Ed25519 подтверждает автора и неизменность конкретного JAR. Lua-файлы и EXE этой подписью не подписаны. Подпись не заменяет выбор доверия пользователем.

## Повторная сборка

Приватный ключ хранится отдельно от проекта, не входит в архив или установщик. Не удаляйте его и сохраните защищённую резервную копию: без него нельзя подписывать обновления тем же ключом.

На авторской машине `signing.local.properties` содержит SteamID и путь к ключу. Файл исключён из Git и поставки. Подпись выключена по умолчанию, даже если ключ есть. Только при `zbsSigningEnabled=true` Gradle запускает `signJarZBS` перед упаковкой. Для переноса на другую машину создайте такой локальный файл:

```properties
zbsSigningEnabled=false
zbsSteamID64=76561199013754121
zbsPrivateKeyFile=C:/path/outside/project/ed25519-private.der
```

При возобновлении подписи нужен OpenSSL с Ed25519; скрипт по умолчанию использует OpenSSL из Git for Windows. `installer/sign-jar.ps1` принимает параметр `-OpenSSL` для другого пути. Формат ключа — PKCS#8 DER. При выключенной подписи старые sidecar-файлы в staging удаляются. Установщик неподписанной сборки переносит ранее установленную подпись в резервную папку вне mods.

Проверка установленным ZombieBuddy выполнена с публичным ключом в изолированной памяти теста. Публикация ключа и доверие на реальном сервере должны подтвердиться отдельно; файлы approvals и список доверенных авторов установщик не изменяет.

Официальная документация: [Mod Signing](https://github.com/zed-0xff/ZombieBuddy/blob/master/doc/ModSigning.md).
