version=1
title=WorkshopSentinel [B42]
description=[h1]Workshop update monitoring for dedicated servers[/h1]
description=WorkshopSentinel checks configured Project Zomboid Workshop items and schedules a restart request when updates are detected. Includes an optional client update viewer.
description=
description=[h2]Server features[/h2]
description=[list]
description=[*]Check Workshop every 5 minutes.
description=[*]Request a restart when the server is empty; check players every minute.
description=[*]If players stay, wait 30 minutes, then announce a full 5-minute safe-exit countdown.
description=[*]Dry-run enabled by default: no server shutdown until explicitly configured.
description=[*]Preserve settings and append missing configuration options after upgrades, with a backup.
description=[*]Works with PauseEmpty. Keeps routine logs in its own file without per-item console spam.
description=[/list]
description=
description=[h2]Installation[/h2]
description=Requires Project Zomboid Build 42 and the ZombieBuddy Java agent on the dedicated server. A Workshop subscription alone does not install the Java agent.
description=Server Mods: WorkshopSentinel. Keep WorkshopSentinelClient out of the server Mods list.
description=Optional client Mods: WorkshopSentinelClient. Provides automatic update notifications, local mod version tracking and MLOS support. No client Java agent is required for this component.
description=With clientOptional=true, the server core is excluded from required client mods. Adding this Workshop item to WorkshopItems can still trigger a Steam download independently of Mods.
description=
description=[h2]Configuration and restart behavior[/h2]
description=Configuration is created at Zomboid/WorkshopSentinel/<serverName>/WorkshopSentinel.properties. New options are added automatically on startup without resetting your values.
description=Defaults: dryRun=true, shutdownEnabled=false, shutdownAdapter=marker. The restart marker is informational; use your external supervisor for relaunch and Workshop downloads.
description=The optional pz-quit-experimental adapter requests a graceful shutdown only. It does not relaunch the server. Read README before enabling live shutdown.
description=Without a verified installed baseline, the first successful Steam response establishes a session baseline; it does not prove installed files are current.
description=The Java JAR is unsigned. ZombieBuddy may ask again after Java updates; author trust and approval are handled by ZombieBuddy before this mod starts.
description=
description=[h2]Compatibility and source[/h2]
description=Conflicts with ServerAutoUpdate_B42 variants. Avoid running multiple independent restart controllers. Source: https://github.com/i218/ZomboidWorkshopSentinel
description=Steam API requests are made for Workshop checks. No mod archive download or Steam account credentials are handled by the mod.
description=
description=[h2]По-русски[/h2]
description=Монитор обновлений Workshop для dedicated server Build 42. Проверка каждые 5 минут; ожидание пустого сервера либо 30 минут и предупреждение за 5 минут. Нужен установленный Java agent ZombieBuddy на сервере.
description=На сервере включайте WorkshopSentinel. WorkshopSentinelClient — необязательный клиентский компонент, на сервере его включать не нужно. Клиентская часть проверяет обновления автоматически и поддерживает локальные моды и MLOS.
description=По умолчанию включён dry-run: остановки нет. Конфиг создаётся и дополняется автоматически с сохранением настроек. Маркер перезапуска требует внешнего супервизора; experimental shutdown только завершает сервер, но не запускает его заново.
